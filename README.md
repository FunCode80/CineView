# 🎬 CineView - Movie Explorer

CineView is een moderne webapplicatie gebouwd met **React** en de **TMDB API**. Hiermee kunnen gebruikers populaire films ontdekken en hun favoriete titels zoeken.

## 🚀 Live Demo
https://cine-view-dusky.vercel.app/

## 🛠 Features
- **Real-time Data:** Koppeling met de [TMDB API](https://www.themoviedb.org).
- **Zoekfunctie:** Zoek direct in een database van duizenden films.
- **Responsive Design:** Geoptimaliseerd voor desktop, tablet en mobiel.
- **Modern UI:** Gebouwd met CSS Grid en Flexbox.

## 🧠 Tech Stack
- **Frontend:** React (Vite)
- **State Management:** React Hooks (`useState`, `useEffect`)
- **API:** REST API via Fetch
- **Deployment:** Vercel

## ⚙️ Installatie
1. Clone deze repo: `git clone https://github.com`
2. Installeer dependencies: `npm install`
3. Voeg je `.env` bestand toe met je `VITE_TMDB_API_KEY`.
4. Start de app: `npm run dev`



## omschrijving App
CineView
Een moderne, responsive webapplicatie gebouwd met React en Vite, waarmee gebruikers films kunnen ontdekken, zoeken en hun favorieten kunnen beheren. De app haalt real-time data op via de TMDB (The Movie Database) API.
🚀 Features

    Real-time Data: Integratie met de TMDB API voor populaire en trending films.
    Geavanceerd Zoeken: Gebruikers kunnen direct zoeken in de uitgebreide database van TMDB.
    Favorieten Systeem: Voeg films toe aan je persoonlijke lijst. Dankzij LocalStorage blijven je favorieten bewaard, zelfs na het verversen van de pagina.
    Multi-page Navigatie: Gebruik van React Router v6 voor een naadloze Single Page Application (SPA) ervaring met specifieke routes voor Home, Populair en Favorieten.
    Paginering: Blader door honderden pagina's met populaire films met een dynamisch pagineringssysteem.
    Responsive Design: Een "Netflix-style" interface die volledig geoptimaliseerd is voor desktop, tablet en mobiel met behulp van CSS Grid en Flexbox.
    User Experience: Inclusief loading spinners, hover-effecten en interactieve iconen via Lucide React.

🛠 Tech Stack

    Frontend: React (Hooks: useState, useEffect)
    Build Tool: Vite
    Routing: React Router DOM
    Styling: Modern CSS3 (Custom Variables, Grid, Flexbox)
    Icons: Lucide React
    API: TMDB REST API
    Deployment: Vercel
